❓ O que é um Favicon?

Favicon é o pequeno ícone que aparece na aba do navegador, nos favoritos e em atalhos. Ele ajuda a identidade visual do site e facilita reconhecimento rápido.

Exemplo: ícone da sua marca, iniciais estilizadas ou um símbolo simples legível em tamanho reduzido.

📐 Formatos e tamanhos recomendados

  • ICO — formato tradicional (bom para compatibilidade com navegadores antigos).
  • PNG — comum e simples (use 16×16, 32×32, 48×48, 96×96 se quiser várias versões).
  • SVG — vetorial, escalável; excelente para ícones simples e modernos (suporte crescente).
  • Apple touch icon — 180×180 (para iOS home screen).
  • Android / PWA — 192×192 e 512×512 (usado no manifest).

Regra prática: mantenha o ícone simples (sem textos pequenos), contraste forte e teste legibilidade em 16×16 px.

💾 Como adicionar (exemplos prontos)

Coloque essas linhas dentro do <head> do seu HTML:

<!-- Fallback tradicional (ICO) -->
<link rel="icon" href="/favicon.ico">

<!-- PNG (boa opção moderna) -->
<link rel="icon" type="image/png" sizes="32x32" href="/favicon-32x32.png">

<!-- SVG (se suportado) -->
<link rel="icon" type="image/svg+xml" href="/favicon.svg">

<!-- Apple touch (iOS) -->
<link rel="apple-touch-icon" sizes="180x180" href="/apple-touch-icon.png">

<!-- Safari pinned tab (SVG) -->
<link rel="mask-icon" href="/safari-pinned-tab.svg" color="#5bbad5">

Dica: oferecer SVG + PNG/ICO garante compatibilidade e qualidade.

📱 Manifest (PWA / atalhos mobile)

Inclua um arquivo site.webmanifest (ou manifest.json) e referencie no <head>:

<link rel="manifest" href="/site.webmanifest">


{
  "name": "Meu Site",
  "short_name": "Site",
  "icons": [
    { "src": "/icons/icon-192.png", "sizes": "192x192", "type": "image/png" },
    { "src": "/icons/icon-512.png", "sizes": "512x512", "type": "image/png" }
  ],
  "theme_color": "#ffffff",
  "background_color": "#ffffff",
  "display": "standalone"
}

🧪 Testar e dicas rápidas

  • Depois de atualizar o favicon, limpe o cache ou abra a página em janela anônima (CTRL+Shift+N).
  • Use o DevTools → Application → Manifest / Icons para inspecionar as imagens.
  • Se o ícone não atualiza, experimente renomear o arquivo (ex: favicon-v2.png) e atualizar o link; assim o browser busca novo recurso.
Ferramentas úteis: geradores como favicon.io (cria ICO, PNG e snippets) — ótimo para testar rapidamente.
