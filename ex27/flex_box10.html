flex-shrink / flex-grow

por: Ailton A. Nakata

Para valores menores: flex-shrink

📌 flex-shrink: 1;

Diz se o item pode encolher quando faltar espaço no container. O valor 1 significa que ele pode encolher proporcionalmente. O valor 0 significa que ele não encolhe nunca.

Se uma caixa tiver flex-shrink: 0, ela “resiste” e as outras encolhem mais para caber.

Para valores maiores: flex-grow

📌 flex-grow: 0;

Indica se o item pode crescer para ocupar espaço extra dentro do container. O valor 0 não cresce. O valor 1 cresce proporcionalmente.

Exemplo mental rápido: - Sobrou espaço no container? grow 0 = não ocupa grow 1 = ocupa proporcionalmente
