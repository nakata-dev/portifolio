flex-Shrink / grow

por: Ailton A. Nakata

Para valores menores: flex-shrink

📌 1. flex-shrink: 1;

Significado: diz se o item pode encolher quando faltar espaço no container.
O valor 1 significa que ele pode encolher proporcionalmente.
O valor 0 significa que ele não encolhe nunca, mesmo que estoure o container.

✅ Exemplo prático

Imagine 3 caixas dentro de um display: flex; e a largura total delas é maior que o container:
Se todas têm flex-shrink: 1, elas vão encolher de forma igual.
Se uma tiver flex-shrink: 0, essa caixa não encolhe, e as outras terão que encolher mais para caber.


Para valores maiores flex-grow


📌 2. flex-grow: 0;

Significado: indica se o item pode crescer para ocupar espaço extra dentro do container.
O valor 0 significa que ele não cresce nunca, mesmo que sobre espaço.
O valor 1 significa que ele cresce proporcionalmente para ocupar o espaço livre.

✅ Exemplo prático

Se um container tiver 800px e você colocar duas caixas de 200px cada (total 400px):
Com flex-grow: 0, elas continuam com 200px e o espaço sobrando fica vazio.
Com flex-grow: 1, elas crescem para ocupar igualmente os 400px restantes(ficando com 400px cada).
