Em Mobile.css:

header, header > nav: Isso significa : selecione o elemento "header" e, separadamente, selecione o elemento "nav" que é um filho direto do "header". É como se você estivesse apontando para duas coisas: o cabeçalho inteiro e a barra de navegação que está dentro dele.


flex-flow: Essa é uma propriedade abreviada que combina duas outras: flex-direction e flex-wrap.

column : Esta parte do comando (flex-direction: column) diz que os elementos dentro do contêiner flexível devem ser organizados em uma coluna, de cima para baixo. Em vez de ficarem lado a lado (que é o padrão do flex-direction: row), eles vão se empilhar.

nowrap: Esta parte (flex-wrap: nowrap) diz que os elementos não devem quebrar para a próxima linha. Se eles excederem o espaço disponível, eles simplesmente vão "transbordar" ou ficar comprimidos, mas não passarão para uma nova linha.

    color: white;
    padding: 10px;
}

    /*border: 1px dotted black;*/
