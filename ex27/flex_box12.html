Em mobile.css

header, header > nav: Isso significa: selecione o elemento header e, separadamente, selecione o nav que é filho direto do header.

flex-flow: é uma propriedade abreviada que combina flex-direction e flex-wrap.

column: organiza os itens de cima para baixo (equivale a flex-direction: column).

nowrap: não permite quebra de linha (equivale a flex-wrap: nowrap). Se exceder o espaço, pode “espremir” ou transbordar, mas não quebra.

Em style.css

@charset "UTF-8";
*{
    margin: 0px;
    padding: 0px;
    box-sizing: border-box;
}
body{
    font-family: Arial, Helvetica, sans-serif;
    font-size: 1em;
    background-color: lightgray;
    width: 100vw;
    height: 100vh;
}
header{ /*Flexbox - PAI*/
    display: flex;
    flex-flow: row wrap;
    justify-content: space-between;
    align-items: center;

    background-color: gray;
    color: white;
    padding: 10px;
}

header > h1{
    /*border: 1px dotted black;*/
    margin: 10px;
    text-shadow: 3px 3px 5px rgba(0, 0, 0, 0.507);
    flex: 0 0 200px; /*flex fixo em 200px*/
}
header > nav > a{
    font-family: Arial, Helvetica, sans-serif;
    background-color: black;
    color: white;
    padding: 10px;
    margin: 5px;
    font-size: 1em;
    border-radius: 5px;
    text-decoration: none;
    text-align: center;
}

header > nav > a:hover{
    background-color: white;
    color: black;
    transition: background-color 1s;
}

header > nav{
    /*border: 1px dotted black;*/
    display: flex;
    flex-flow: row wrap;
    justify-content: flex-end;
}

main{
    border-radius: 10px;
    background-color: white;
    margin: 10px;
    text-align: justify;
    text-indent: 30px;
    line-height: 1.8;
    padding: 20px;
    box-shadow: 2px 2px 3px rgba(0, 0, 0, 0.548);
}
