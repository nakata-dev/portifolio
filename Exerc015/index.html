Tipos de links (na prática)

O elemento base é sempre <a href="...">. O que muda é o destino e alguns atributos.

🟢 Interno entre páginas

  • Ir para a Página 02 (mesmo site) 
<a href="pagina02.html" rel="next">Ir para a Página 02</a>

🟣 Externo outro site

  • Abrir Curso em Vídeo no YouTube
Boa prática: quando usar target="_blank", use também rel="noopener noreferrer" por segurança. 
<a href="https://exemplo.com" target="_blank" rel="noopener noreferrer">
  Abrir site em nova aba
</a>

🟠 Download arquivo

  • Baixar arquivo em PDF
Nota: alguns navegadores podem abrir PDF na aba mesmo com download, dependendo das configurações do usuário. 
<a href="download/arquivo.pdf" download type="application/pdf">
  Baixar arquivo em PDF
</a>

🔵 Âncora na mesma página

  • Ir para a seção de dicas (âncora) 
<a href="#secao-dicas">Ir para a seção de dicas</a>

<!-- ...mais abaixo na página... -->
<h2 id="secao-dicas">Dicas</h2>

Dicas rápidas (que valem ouro)

  • Texto do link: evite “clique aqui”. Prefira “Baixar PDF”, “Ir para Página 02”, etc.
  • Link externo: use target="_blank" + rel="noopener noreferrer".
  • Organização: se repetir estilos, vire classe (HTML limpo, CSS manda no visual).
