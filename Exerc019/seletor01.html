Seletor ID

Como usar id no HTML e selecionar com # no CSS (com exemplos práticos).

Voltar para HTML Contato

HTML básico

Ao criar uma id no HTML, você deve prestar atenção no nome (sem espaços e preferencialmente sem acentos). A ideia da id é identificar um elemento de forma única na página.

Exemplos de uso de id no HTML:

<p id="principal">...</p>
<p id="texto01">...</p>
<h1 id="primeiro_h1">...</h1>

Parâmetro para CSS

No CSS, tudo que é id no HTML é selecionado com # (cerquilha). Exemplo: #principal.

Observação: @charset "utf-8"; pode ser usado no início do CSS, mas hoje é raro ser necessário se o arquivo já estiver em UTF-8 (o comum).

CSS básico

Exemplo de configuração com #principal no CSS:

body{
  background-color: rgb(205, 255, 203);
  font-family: Arial, Helvetica, sans-serif;
}

h1{
  color: rgb(4, 109, 0);
}

#principal{
  text-align: center;
  background-color: rgb(4, 109, 0);
  color: white;
}

h2{
  color: rgb(73, 109, 71);
}

p{
  text-align: justify;
  text-indent: 30px;
}

Diferença entre id e class

id deve ser único na página (um elemento). Já class pode se repetir em vários elementos (vários itens com o mesmo estilo).

Regra prática: use class para estilo reutilizável e id para algo único (ou para ancoragem/JS, quando fizer sentido).

Exemplo (não recomendado repetir a mesma id): 

<p id="titulo">...</p>
<!-- Evite fazer isso: -->
<h2 id="titulo">...</h2>
