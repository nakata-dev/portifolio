Estilos Inline

O famoso style="" dentro das tags: útil em testes rápidos, perigoso em projetos reais.

Voltar para HTML Contato

O que é estilo inline?

  • Inline é quando você coloca CSS direto na tag: <h2 style="color: blue">
  • Vantagem: rápido para testar.
  • Desvantagem: vira bagunça, repete muito, dificulta manutenção e padronização.
Regra prática: se você repetiu um mesmo style duas vezes, já era hora de virar classe.

Como fica no HTML (limpo)

<h2 class="demo-title-1">Capítulo 1.1</h2>
<p class="demo-p-1">...</p>

<h2 class="demo-title-2">Capítulo 1.2</h2>
<p class="demo-p-2">...</p>

<h2 class="demo-title-3">Capítulo 2</h2>
<p class="demo-p-3">...</p>

E no CSS (reutilizável)

.demo-title-1 { color: lightslategrey; }
.demo-title-2 { color: blue; }
.demo-title-3 { color: rgb(1, 71, 71); }

.demo-p-1 { font-family: cursive, "Arial Narrow", Arial, sans-serif; }
.demo-p-2 { font-family: "Gill Sans", "Gill Sans MT", Calibri, "Trebuchet MS", sans-serif; font-size: 20px; }
.demo-p-3 { font-family: Impact, Haettenschweiler, "Arial Narrow Bold", sans-serif; }
Dica final: seu “eu do futuro” vai agradecer quando você precisar trocar uma cor e fizer isso em 1 lugar (CSS), não em 17 tags 😄
