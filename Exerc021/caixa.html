Modelo de Caixas

Box-level vs inline: border, padding, margin e outline.

Voltar para HTML Contato

Demonstração

Box-level

Parágrafos e títulos são exemplos de box-level (ocupam a largura inteira). Já os links são inline por padrão (ficam “na linha”), mas podem receber borda/padding e virar uma “caixa” visual.

Regra: border fica entre o conteúdo e o exterior. padding é “acolchoamento” interno. margin é o espaço externo. outline não ocupa espaço (fica por fora).

CSS (exemplo)

.box-level{
  display: flex;
  justify-content: center;
  align-items: center;

  width: min(320px, 100%);
  aspect-ratio: 1 / 1;

  background-color: lightgray;
  border: 10px solid darkslategray;
  padding: 10px;
  margin: auto;
}

.inline-box{
  display: inline-block;
  border: 4px solid darkslategray;
  padding: 8px 10px;

  outline: 5px dashed rgba(250, 128, 114, 0.60);
  outline-offset: 4px;
}
