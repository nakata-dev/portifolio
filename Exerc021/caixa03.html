Borda com imagem

Como aplicar bordas decorativas usando border-image.

Voltar para HTML Contato

Demonstração

Teste de Borda

Usando border-image com a imagem borda.png.

Se a borda não aparecer, confira se o arquivo borda.png está na mesma pasta deste HTML.

Dica: você precisa ter uma borda definida (border) para o border-image funcionar.

CSS usado

h2{
  border: 13px solid transparent;
  padding: 10px;
  border-image: url('borda.png') 27 repeat;
  text-align: center;
}
