Monoformatação

Como exibir código, criar citações, abreviações e inverter direção de texto no HTML.

Voltar para HTML Contato

Código fonte: <code> e <pre>

A tag <code> deixa o texto monoformatado. Quando você junta com <pre>, você preserva quebras de linha e indentação. 

num = int(input("Digite um número"))
if num % 2 == 0:
    print(f"O número {num} é PAR")
else:
    print(f"O número {num} é ÍMPAR")

print("Fim do programa")
Dica: use <code> para trechos curtos e <pre><code> para blocos.

Citações curtas: <q>

Como diria o pai de um amigo: o computador é um burro muito rápido.

Use <q> para citações na mesma linha do texto.

Citações longas: <blockquote> e fonte

Exemplo de citação em bloco:

Em HTML, existem três principais elementos para lidar com citações: q, blockquote e cite. O q é usado para citações curtas em linha, o blockquote para citações longas e o cite para indicar a fonte da citação.

Fonte (exibida para o leitor): W3C HTML (blockquote element)

Boa prática: o atributo cite ajuda, mas mostrar a fonte como link deixa a página mais transparente (e útil).

Abreviações: <abbr>

Estou estudando HTML e CSS. Estou adorando.

Texto invertido: <bdo>

Texto invertido / Texto normal.

A tag <bdo dir="rtl"> inverte o sentido da escrita, enquanto <bdo dir="ltr"> mantém a direção normal.
