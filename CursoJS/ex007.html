Operadores parte II

por: Ailton A. Nakata

Operadores Relacionais

  • 5 > 2 = true
  • 7 < 4 = false
  • 8 >= 8 = true
  • 9 <= 7 = false
  • 5 == 5 = true
  • 4 != 4 = false

Operadores de Identidade

  • 5 = = 5 = true
  • 5 = = '5' = true
  • 5 = = = '5' = false
  • 5 = = = 5 = true

Operadores Lógicos

  • ! = Negação
  • && = Conjunção
  • || = Disjunção

Negação:

  • ! true = false (Uma coisa que não é verdadeira é falsa)
  • ! false = true (Uma coisa que não é falsa é verdadeira)

Conjunção

  • true && true = true
  • true && false = false
  • false && true = false
  • false && false = false

Disjunção

  • true || true = true
  • true || false = true
  • false || true = true
  • false || false = false

Ordem de Precedência

  • () ** / ..
  • > < >= ..
  • ! = não
  • && = e
  • || = ou

Operador Ternário

  • teste ? true : false
