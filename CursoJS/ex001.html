Primeiro comando em JavaScript

por: Ailton A. Nakata

Diálogo com o usuário

  • window.alert("Mensagem"); → Mostra um alerta.
  • window.confirm("Você tem certeza?"); → Retorna true ou false.
  • window.prompt("Digite algo:"); → Retorna o texto digitado ou null.

Controle de janelas e navegação

  • window.open("https://site.com", "_blank"); → Abre nova aba/janela.
  • window.close(); → Fecha a janela atual (se tiver sido aberta por script).
  • window.print(); → Abre a caixa de impressão.
  • window.location → Objeto para manipular URL. Ex.: window.location.href = "https://google.com";

Temporizadores

  • window.setTimeout(funcao, tempo); → Executa uma vez após X milissegundos.
  • window.setInterval(funcao, tempo); → Executa repetidamente a cada X ms.
  • window.clearTimeout(id); → Cancela um setTimeout.
  • window.clearInterval(id); → Cancela um setInterval.

Dimensões e rolagem

  • window.innerWidth / window.innerHeight → Largura/altura da área visível.
  • window.scrollX / window.scrollY → Distância rolada horizontal/vertical.
  • window.scrollTo(x, y); → Rola para posição exata.
  • window.scrollBy(x, y); → Rola relativo à posição atual.
