Estrutura: While; Do While e For

por: Ailton A. Nakata

Estrutura : While (enquanto)

var = 1

while (c<=6) {

console.log(`passo ${c}`)

c++

}





Estrutura : Do While (faça / enquanto)

var = 1

do {

console.log(`passo ${c}`)

c++

} while (c<=6)





Estrutura : For

for (var = 1; c<=6; c++) {

console.log(c)

}
