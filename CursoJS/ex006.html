Operadores parte I

por: Ailton A. Nakata

Aritméticos

  • 5 + 2 = 7
  • 5 - 2 = 3
  • 5 * 2 = 10
  • 5 / 2 = 2.5
  • 5 % 2 = 1
  • 5 ** 2 = 25

Ordem de Precedência

  1. () : Entre parenteses
  2. ** : Ao quadrado
  3. * / % : Multiplicação; Divisão; Resto
  4. + - : Soma; Subtração

Atribuições Simples

  • var a = 5 + 3 = 8
  • var b = a % 5 = 3
  • var c = 5 * b**2 = 45
  • var d = 10 - a / 2 = 6
  • var e = 6 * 2 / d = 2
  • var f = b % e + 4 / e = 3

Simplificando Atribuições

  • var n = 3
  • n = n + 4 ou n+ = 4
  • n = n - 5 ou n- = 5
  • n = n * 4 ou n* = 4
  • n = n / 2 ou n/ = 2
  • n = n** 2 ou n** = 2
  • n = % 5 ou n% = 5

Incremento

  • var x = 5
  • x = x + 1 ou x+ = 1 ou x++
  • x = x - 1 ou x- = 1 ou x--
