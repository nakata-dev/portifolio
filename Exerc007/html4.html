Tags Obsoletas

Como identificar recursos antigos (deprecated) e evitar problemas de acessibilidade e compatibilidade.

Voltar para HTML Contato

Onde conferir a lista oficial

Você pode ver a lista completa de elementos e atributos obsoletos na documentação oficial.

Link: W3C (lista de elementos obsoletos)

Por que evitar? Tags/atributos obsoletos podem quebrar em navegadores, atrapalhar leitores de tela e dificultar manutenção do site.

Exemplo: a tag <marquee>

Marquee serve para fazer este letreiro se movimentar na tela.

Apesar de funcionar em alguns navegadores, <marquee> não é recomendado hoje: é obsoleto e prejudica acessibilidade.

Alternativa moderna (CSS)

Em vez de <marquee>, você pode animar com CSS. Exemplo simples: 

<div class="ticker" aria-label="Letreiro animado">
  <div class="ticker-track">Letreiro animado com CSS (mais controlável e acessível).</div>
</div>

<style>
  .ticker{
    overflow:hidden;
    border:1px dashed rgba(0,0,0,.2);
    border-radius:12px;
    padding:12px;
    background:#fff;
  }
  .ticker-track{
    display:inline-block;
    white-space:nowrap;
    padding-left:100%;
    animation: ticker 10s linear infinite;
  }
  @keyframes ticker{
    from { transform: translateX(0); }
    to   { transform: translateX(-100%); }
  }
  @media (prefers-reduced-motion: reduce){
    .ticker-track{ animation:none; padding-left:0; }
  }
</style>
Dica: o trecho prefers-reduced-motion respeita usuários que preferem menos animação.
