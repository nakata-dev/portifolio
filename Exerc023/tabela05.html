Entendendo o scope

O atributo scope em HTML é usado dentro de tabelas (<table>) para indicar a quais células de dados (<td>) um cabeçalho (<th>) está associado. Ele melhora a acessibilidade, ajudando leitores de tela a entenderem a estrutura da tabela. Valores principais: • scope="col" → o <th> vale para toda a coluna. • scope="row" → o <th> vale para toda a linha. • scope="colgroup" → o <th> vale para um grupo de colunas. • scope="rowgroup" → o <th> vale para um grupo de linhas.
