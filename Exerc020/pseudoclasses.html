Explicação: :hover é uma pseudoclasse que ativa quando o mouse passa por cima do elemento.

Orientação: CSS

.box{
  display: inline-flex;      /* Ativa flexbox */
  justify-content: center;   /* Centraliza horizontal */
  align-items: center;       /* Centraliza vertical */
  background-color: lightgray;
  border: 1px solid black;
  height: 120px;
  width: 120px;
  font-size: 1.4em;
}

.box:hover{
  background-color: yellow;  /* muda a cor ao passar o mouse */
}
