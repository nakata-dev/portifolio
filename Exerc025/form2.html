<input> - é usada para criar campos interativos

Exemplo de inputs

    
    <input type="text" placeholder="Digite seu nome">
    


    <input type="email" placeholder="Digite seu e-mail">
    


    <input type="password" placeholder="Digite sua senha">
    


    <input type="checkbox"> Aceito os termos
    


    <label>: serve para associar um texto descritivo a um campo de formulário
    
    
    
Exemplo de Label

    
    <label for="nome">Nome:
    


    </label>
    


    <input type="text" id="nome" name="nome">
    


    Se o atributo for do <label> aponta para o id do <input>.
    
    Assim, se você clicar no texto “Nome:”, o cursor vai direto para o campo de texto.
