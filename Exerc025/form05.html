Radio e Checkbox

Autor: Ailton A. Nakata

Radio: você escolhe apenas uma opção quando o atributo name é o mesmo (ex.: name="sexo").

Checkbox: você pode marcar várias opções ao mesmo tempo.

Sexo

Só dá para escolher 1 porque o name é o mesmo.

Esportes favoritos

Aqui você pode marcar mais de 1 (checkbox).

Dica: para enviar múltiplos esportes de um jeito mais organizado para o servidor, dá pra usar name="esportes[]". Se quiser, eu te mostro na próxima.
