Range + Output (valor ao vivo)

Autor: Ailton A. Nakata

O <output> é perfeito para mostrar um valor que muda conforme o usuário interage. Aqui vamos ligar o input type="range" ao output.

Controle
50

Arraste a barra e veja o valor mudar automaticamente.

Dica: usar JS fora do HTML deixa seu código mais limpo (evita oninput="" dentro da tag).

Comando que atualiza o valor

oninput="ival.innerHTML = Number(inum.value)"

Saída de valor

<output id="ival">50</output>

Estrutura completa

<label for="inum">Número</label>
<input type="range" name="num" id="inum" min="0" max="100" value="50"
  oninput="ival.innerHTML = Number(inum.value)">
<output id="ival">50</output>
