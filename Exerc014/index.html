🎨 Estilo Interno (CSS no <style>)

Quando usar, quando evitar e um exemplo prático deixando o HTML mais limpo.

Voltar para HTML Contato

O que é estilo interno?

Estilo interno é quando você escreve CSS dentro do próprio HTML, usando a tag <style> no <head>. É útil para páginas únicas ou aulas, mas para sites reais o ideal é migrar para um CSS externo.

Regra prática: se o mesmo estilo vai aparecer em várias páginas, ele quer morar no site.css.

🟡 Intermediário ruim vs bom

O erro clássico é misturar “um monte de style="..."” no HTML. O correto é criar classes (mesmo que o CSS esteja interno). 

<!-- Ruim (inline repetido) -->
<p style="text-align: justify; line-height: 1.8;">...</p>
<p style="text-align: justify; line-height: 1.8;">...</p>

<!-- Bom (classe + CSS interno) -->
<style>
  .text-justify{ text-align: justify; line-height: 1.8; }
</style>

<p class="text-justify">...</p>
<p class="text-justify">...</p>
Resumo: mesmo usando CSS interno, prefira classes. Seu HTML respira melhor.

🔴 Avançado quando usar e quando evitar

Quando faz sentido usar CSS interno

  • Página única (ex.: landing isolada, protótipo, exercício).
  • Aula/didática (como esta página).
  • Experimento rápido antes de colocar no CSS global.

Quando NÃO usar

  • Sites com várias páginas (vira repetição e bagunça).
  • Projetos com manutenção (você vai esquecer onde está o estilo).
  • Quando performance e cache importam (CSS externo é melhor para reaproveitar cache).
Dica de performance: CSS externo permite cache do navegador. CSS interno precisa ser baixado/parseado toda vez.
