Links externos

Básico

Link externo é quando você aponta para outro site (fora do seu domínio). Você cria um link com a tag <a> e o destino no href.

🧠 Por que isso importa? Links externos passam credibilidade (referências) e guiam o usuário, mas precisam de boas práticas para não abrir brechas de segurança.
  • Repositórios do professor: Guanabara no GitHub
  • Canal gratuito: Curso em Vídeo no YouTube

Intermediário

Quando você usa target="_blank", o link abre em uma nova aba/janela. Isso pode ser bom quando você não quer “tirar” a pessoa do seu site.

⚠️ Atenção: sempre combine target="_blank" com rel="noopener noreferrer". É uma proteção importante e também melhora performance em alguns casos.

🔎 Exemplo (snippet seguro):

<a href="https://exemplo.com"
   target="_blank"
   rel="noopener noreferrer">
  Visitar site externo
</a>

Avançado (boas práticas e pegadinhas)

  • noopener: impede que a aba aberta controle sua página via window.opener (evita “tabnabbing”).
  • noreferrer: além do noopener, reduz envio de referrer para o site destino (privacidade).
  • Texto do link: evite “clique aqui”. Prefira algo que faça sentido fora de contexto (acessibilidade + SEO).
  • Link em ícone: se o link for só um ícone, adicione aria-label no <a>.
✅ Dica: se o link aponta para arquivo pesado (ex.: PDF grande), avise no texto: “Baixar catálogo (PDF, 2 MB)”. Isso reduz fricção e aumenta confiança.

Perguntas rápidas (fixação)

  1. Quando faz sentido abrir um link externo em nova aba?
  2. Qual atributo você sempre combina com target="_blank" e por quê?
  3. Por que “clique aqui” é um texto fraco para links?

Links locais

Básico

Links locais navegam dentro do seu próprio projeto (suas páginas HTML). O segredo é usar caminhos relativos: você escreve o caminho a partir da página atual.

🔎 Exemplo:

  • Ir para a segunda página do meu site

Intermediário

Pense em “mapa de pastas”. Se o arquivo está na mesma pasta, você só precisa do nome. Se estiver em outra, você escreve o caminho.

🔎 Exemplo (mesma pasta):

<a href="pag002.html">Ir para a página 2</a>
✅ Dica: se o link “não funciona”, o motivo mais comum é: nome do arquivo diferente (maiúsculas/minúsculas contam em muitos servidores).

Avançado (boas práticas e pegadinhas)

  • Evite espaços em nomes de arquivos: prefira minha-pagina.html. (Menos dor com URL encoding.)
  • Padronize tudo em minúsculo: contato.html, projetos.html.
  • Link para seção (âncora): crie um id e aponte com #: <a href="#precos">Ver preços</a>.
  • Conteúdo do link: deixe o destino claro. Ex.: “Ver portfólio” é melhor que “aqui”.

Mini-checklist

  • O arquivo existe com o mesmo nome?
  • Está na pasta certa?
  • Não tem erro de maiúsculas/minúsculas?
  • O texto do link faz sentido sozinho?

Perguntas rápidas (fixação)

  1. O que é um caminho relativo?
  2. Qual é o erro mais comum quando um link local quebra?
  3. Como você cria um link para uma parte específica da página?

Links em subpastas

Básico

Se a página destino está dentro de uma subpasta, você escreve: nome-da-pasta/arquivo.html.

  • Ir para a terceira página do meu site

Intermediário

Pense assim: você está em uma “rua” (pasta atual). Para entrar numa “travessa” (subpasta), você escreve o nome da travessa antes do endereço (arquivo).

🔎 Exemplo (subpasta):

<a href="pag003/pag003.html">Abrir página 3</a>
✅ Dica: para voltar uma pasta, use ../. Ex.: ../index.html (sobe um nível).

Avançado (boas práticas e pegadinhas)

  • ../ sobe um nível. ../../ sobe dois níveis.
  • ./ (pasta atual) quase nunca é necessário, mas pode ajudar a deixar explícito.
  • Cuidado com mover arquivos: se você muda a pasta de uma página, os caminhos relativos podem quebrar.
  • Organização profissional: imagens em /img, estilos em /css, scripts em /js.

🔎 Exemplo (subindo pasta):

<!-- Estou em /paginas/servicos.html e quero ir para /index.html -->
<a href="../index.html">Voltar para o início</a>

Perguntas rápidas (fixação)

  1. O que ../ faz?
  2. Qual a principal pegadinha quando você move uma página de pasta?
  3. Qual estrutura de pastas deixa o projeto mais organizado?

Downloads

Básico

Para sugerir que um arquivo seja baixado, você pode usar o atributo download no link. Ele tenta baixar o arquivo em vez de abrir como página.

  • Baixar livro em PDF
  • Baixar livro em ZIP

Intermediário

Você também pode definir um nome sugerido para o arquivo baixado: download="nome-do-arquivo.pdf".

🔎 Exemplo (com nome):

<a href="/download/catalogo.pdf"
   download="catalogo-2026.pdf"
   type="application/pdf">
  Baixar catálogo (PDF)
</a>
✅ Dica: seja gentil com o usuário: diga o formato e, se possível, o tamanho. Ex.: “Baixar apostila (PDF, 3 MB)”.

Avançado (boas práticas e pegadinhas)

  • Nem sempre baixa: alguns navegadores podem abrir PDF direto, dependendo das configurações do usuário.
  • Cross-origin: por segurança, o download pode ser ignorado em links para outros domínios.
  • type no <a> é “dica” de MIME, mas não substitui a configuração correta do servidor.
  • Profissional: se você controla o servidor, o jeito mais confiável é ajustar headers (ex.: Content-Disposition).
⚠️ Atenção: “forçar download” nem sempre é possível só com HTML. Dependendo do navegador e da origem do arquivo, ele pode ignorar o download.

Perguntas rápidas (fixação)

  1. Para que serve o atributo download?
  2. O que pode fazer um PDF abrir no navegador mesmo com download?
  3. Por que links para outros domínios podem ignorar download?
