Links externos

Links externos abrem para outro site. Use target="_blank" e também rel="noopener noreferrer" por segurança.

  • Repositórios do professor: Guanabara no GitHub
  • Canal gratuito: Curso em Vídeo no YouTube
Boa prática: evite rel="external". Prefira noopener e noreferrer quando usar target="_blank".

Links locais

Você pode navegar entre páginas do seu próprio site:

  • Ir para a segunda página do meu site

Links em subpastas

Para acessar arquivos dentro de subpastas, use o caminho relativo:

  • Ir para a terceira página do meu site
Dica: caminho relativo é basicamente “onde estou agora” + “para onde quero ir”. Se você subir uma pasta, usa ../.

Downloads

Use o atributo download para sugerir download do arquivo. (Alguns navegadores podem abrir PDF inline dependendo das configurações.)

  • Baixar livro em PDF
  • Baixar livro em ZIP
