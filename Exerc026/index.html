Media Queries na prática

Autor: Ailton A. Nakata

Este exemplo mostra como usar Media Queries para adaptar o design a diferentes larguras de tela. Redimensione a janela do navegador (ou teste no celular) para ver a área de demonstração mudar.

  • Desktop (padrão): estilo neutro.
  • Tablet (601px a 900px): a demo muda para laranja.
  • Celular (até 600px): a demo muda para azul.
  • Impressão (print): esconde elementos não essenciais.

Área de demonstração

O estilo aqui muda conforme a largura da tela (sem alterar o tema do site inteiro).

A cor e o estilo deste bloco mudam com as Media Queries!

Dica: use media queries para layout, tipografia e espaçamentos. Para “temas inteiros”, prefira classes e variáveis CSS (fica mais controlável).
