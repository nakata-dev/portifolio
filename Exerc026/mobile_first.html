Media Query (Mobile First)

Autor: Ailton A. Nakata

A ideia do Mobile First é começar o CSS pensando no celular, e ir “liberando” melhorias conforme a tela cresce usando @media.

Neste exemplo, cada ícone (phone/tablet/print/pc/tv) pode ser exibido/ocultado pelas regras do seu media_query.css.

Redimensione a tela ou teste no celular para ver qual ícone fica visível 👇

Dica: normalmente o CSS faz algo assim: #phone { display:block } e os outros ficam display:none, depois cada media query troca qual aparece.
