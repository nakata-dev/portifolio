Olá Mundo!

Seu primeiro HTML: título, parágrafo e separadores, do jeito mais simples possível. Aqui você vai entender o que cada tag faz, por que usamos, e como testar no navegador em minutos.

O que aparece na tela

Este é o seu “primeiro passo”: um <h1> (título), um <p> (parágrafo), e alguns <hr>/<br> para separar. Parece simples, e é mesmo, mas aqui você já aprende a lógica do HTML: marcar significado e deixar o navegador renderizar.

Entendendo as tags (Básico → Intermediário → Avançado)

Básico (para iniciantes)

HTML é a “estrutura” da página. Você usa tags para dizer ao navegador o que cada parte do conteúdo é: título, texto, separador, etc.

🧠 Por que isso importa? Quando você usa a tag certa (como <h1> e <p>), seu site fica mais organizado, mais fácil de manter, e também ajuda em SEO (Google entende melhor sua página).

✅ Dica: Pense assim: HTML não é “enfeite”. É significado. Visual bonito vem depois com CSS.

Intermediário (mais contexto)

  • <h1> é o título principal da página (normalmente deve existir apenas 1 por página).
  • <p> é o parágrafo: o lugar certo para texto comum (explicações, descrições).
  • <hr> cria uma linha horizontal e indica uma “quebra de seção” visual (e também semântica).
  • <br> quebra linha dentro do conteúdo (bom para casos pontuais, não para “montar layout”).

⚠️ Atenção: Muitas quebras com <br> viram bagunça rápido. Em páginas reais, o espaçamento deve ser feito com CSS, porque fica consistente em desktop e mobile.

Avançado (boas práticas e pegadinhas)

  • Semântica primeiro: use headings (h1 → h2 → h3) como uma hierarquia lógica, sem “pular níveis”.
  • SEO e acessibilidade: o Google e leitores de tela usam títulos para navegar e entender o conteúdo.
  • <hr> não é só decoração: ele representa uma separação temática. Se for só “linha bonita”, CSS costuma ser melhor.
  • Pegadinha comum: criar vários <h1> só para “ficar grande”. Melhor usar CSS para tamanho e manter a semântica correta.
✅ Dica (profissional): Quando você quiser “espaço”, prefira CSS. Quando quiser “significado”, prefira HTML.

🔎 Exemplo (coloque dentro do <body>)

Copie o código abaixo, cole dentro do <body> e abra o arquivo no navegador. Você vai ver um título, uma linha, um parágrafo e separadores. 

<h1>Olá Mundo!</h1>
<br>
<hr>
<p>Este é o meu primeiro HTML!</p>
<hr>
<br>
<br>

✅ Teste rápido (2 minutos)

  1. Crie um arquivo: index.html
  2. Cole o exemplo dentro do <body>
  3. Salve e dê duplo clique no arquivo (ou “Open with” no navegador)
  4. Altere o texto “Olá Mundo!” e recarregue (F5)
🧠 Por que isso importa? Você treina o ciclo real de programação: editar → salvar → testar → ajustar. Isso vira automático e acelera seu aprendizado.

Resumo final

  • <h1> é o título principal da página
  • <p> é texto comum em formato de parágrafo
  • <hr> separa “blocos/temas” com uma linha
  • <br> quebra linha, mas use com moderação
  • Espaçamento profissional = CSS (mais consistente)

Mini-checklist (o que você precisa lembrar)

  • Use 1 <h1> por página (na maioria dos casos)
  • Coloque textos em <p>, não soltos
  • Use <br> só quando for realmente quebra de linha
  • Separe seções com estrutura (e depois refine com CSS)

Perguntas rápidas (fixação)

  1. Qual a diferença entre <p> e <br>?
  2. Por que é recomendado ter apenas um <h1> por página?
  3. Quando vale usar <hr> e quando é melhor usar CSS?
  4. Qual é o “ciclo” básico de testar HTML no navegador?
✅ Dica: mais pra frente, a gente vai reduzir o uso de <br> e fazer espaçamentos com CSS (fica mais profissional e consistente). Por enquanto, use o <br> só para sentir o efeito na prática.
