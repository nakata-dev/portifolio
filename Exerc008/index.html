Negrito: <b> vs <strong>

Aqui vai a ideia central: <strong> tem significado (importância/urgência), e <b> é mais “visual” (chamar atenção sem dizer que é importante). Em muitos navegadores os dois ficam em negrito, mas o que muda é o sentido.

Básico (para iniciantes)

Quando usar <strong> ✅

Quando o trecho é realmente importante: avisos, riscos, ações críticas, palavras que mudam o entendimento.

Quando usar <b> ✅

Quando você quer apenas destacar algo “sem peso semântico”: nomes de recursos, palavras-chave visuais, labels dentro do texto.

🧠 Por que isso importa? Leitores de tela e ferramentas de acessibilidade podem dar ênfase diferente para <strong>. Isso melhora a compreensão além do visual.

Intermediário (exemplo que parece igual, mas não é)

Exemplo 1 (importância real): Ao enviar o formulário, confira o número do WhatsApp antes de clicar em “Enviar”.

Exemplo 2 (só destaque visual): Você vai aprender sobre as tags <header>, <main> e <footer>.

Avançado (boas práticas e pegadinhas)

  • Não use <strong> como “estilo”. Se o objetivo é só deixar em negrito, use CSS (font-weight).
  • Evite exagero: se tudo é “muito importante”, nada é importante.
  • Para títulos, use <h1>...<h6>. Para ênfase dentro do texto, aí sim <strong>.

🔎 Exemplo (HTML para copiar)

<p>
  <strong>Atenção:</strong> confirme o e-mail antes de enviar.
</p>

<p>
  Tags do layout: <b>&lt;header&gt;</b>, <b>&lt;main&gt;</b> e <b>&lt;footer&gt;</b>.
</p>

Resumo final

  • <strong> = importância/urgência (semântica)
  • <b> = destaque visual sem “peso” (semântica fraca)
  • Para estilo puro, prefira CSS

Mini-checklist

  • Eu estou marcando importância de verdade?
  • Se for só visual, posso fazer com CSS?
  • Estou evitando exagero de destaque?

Perguntas rápidas

  1. Qual tag você usa para “isso é importante”?
  2. Quando <b> faz mais sentido do que <strong>?

Itálico: <i> vs <em>

Os dois podem parecer iguais na tela (itálico), mas: <em> é ênfase (stress emphasis) e <i> é texto “separado do fluxo normal” (termo estrangeiro, pensamento, definição, etc).

Básico

<em>: muda o sentido da frase, como se você estivesse falando com ênfase. Ex: Eu não disse isso.

<i>: é um “tom editorial”, um trecho diferente do resto. Ex: A palavra hype vem do inglês.

✅ Dica: se você conseguir “ler em voz alta” e perceber a ênfase, provavelmente é <em>. Se for “um termo/expressão”, tende a ser <i>.

Intermediário (um exemplo divertido e didático)

Frase 1: Eu pedi hoje. (ênfase no tempo, muda o foco)

Frase 2: A expressão deadline é comum em equipes de tecnologia. (termo estrangeiro)

Avançado (boas práticas e pegadinhas)

  • Não use <em> só para “italicar”. Se for estilo, use CSS.
  • <em> pode ser aninhado para reforçar ênfase (com parcimônia).
  • Se for título de obra (livro/filme), considere <cite> em vez de <i> (dependendo do caso).

🔎 Exemplo (HTML para copiar)

<p>Eu <em>não</em> falei isso.</p>
<p>A palavra <i>hype</i> aparece muito em marketing.</p>

Resumo final

  • <em> = ênfase que muda o sentido
  • <i> = termo/idioma/pensamento/diferente do texto normal
  • Para estilo puro, use CSS

Mini-checklist

  • Isso é ênfase de voz (em) ou um termo editorial (i)?
  • Eu estou usando itálico só por estilo?

Perguntas rápidas

  1. Qual tag você usa para “stress emphasis”?
  2. Dê um exemplo real de uso para <i>.

Texto marcado: <mark>

Pense no <mark> como um marca-texto: ele destaca um trecho por ser relevante naquele contexto. Um uso clássico é destacar termos em resultados de busca.

Básico

Podemos criar um texto marcado usando a tag MARK.

Também podemos usar style para trocar a cor: marcação com outra cor.

🧠 Por que isso importa? “Marcar” não é o mesmo que “dar ênfase”: <em> é voz/ênfase; <mark> é relevância no contexto (ex.: termo encontrado).

Intermediário (mini caso real: resultado de busca)

Você pesquisou por: “HTML”

Resultado: Aprenda HTML e HTML semântico para criar páginas modernas.

Avançado (boas práticas e pegadinhas)

  • Use com moderação: se você marca tudo, o destaque perde sentido.
  • Acessibilidade: marque com contraste decente. Não dependa só de cor para passar significado.
  • Não confunda com “seleção do usuário”: ::selection é outra coisa (CSS).

🔎 Exemplo (HTML para copiar)

<p>Resultado para: <strong>HTML</strong></p>
<p>Aprenda <mark>HTML</mark> semântico e <mark>HTML</mark> moderno.</p>

Resumo final

  • <mark> = destaque por relevância no contexto
  • Uso clássico: resultados de busca
  • Evite marcar “o texto inteiro”

Mini-checklist

  • O trecho marcado é relevante “agora”?
  • O contraste está bom?
  • Eu não marquei coisa demais?

Perguntas rápidas

  1. Qual diferença de intenção entre <mark> e <em>?
  2. Onde você usaria <mark> em um site real?

Várias marcações com a mesma cor

Básico

Primeiro você deixa todos os textos marcado de amarelo básico.

Como eu vou fazer neste exemplo aqui.

Em seguida, na cabeça (HEAD) crie uma tag STYLE e personalize o mark.

Intermediário (o jeito “limpo”)

Em vez de colocar style em cada <mark>, você define 1 regra no CSS e pronto: todas as marcações ficam consistentes. 

<style>
  mark {
    background-color: limegreen;
  }
</style>
✅ Dica: consistência dá aparência profissional. Assim o texto de todas as marcações ficará verde.

Avançado (controle por “tema” sem bagunça)

  • Se o seu site tiver tema escuro/claro, você pode ajustar mark para manter contraste.
  • Evite cores neon em textos longos. Marcação é para trechos pequenos.

Resumo final

  • Preferir CSS global/local ao invés de style repetido
  • Marcação boa = contraste + moderação

Mini-checklist

  • Eu padronizei a cor em um só lugar?
  • O contraste está ok no fundo do site?

Texto grande e pequeno: <big> / <small>

Aqui tem uma pegadinha clássica: <big> é obsoleto e não deve ser usado. Para aumentar texto, use CSS (font-size). Já <small> ainda existe e é útil para “letras miúdas” e observações.

Básico

Estamos criando um texto grande e um texto pequeno.

⚠️ Atenção: <big> é considerado obsoleto. Para “tamanho”, o ideal é usar CSS (font-size) e manter a semântica com HTML.

Intermediário (o jeito certo de “aumentar”)

Quer texto maior? Faça assim: 

<p>Um texto normal e um <span style="font-size:1.25rem; font-weight:700;">trecho maior</span>.</p>

Avançado (quando <small> brilha)

Use <small> para observações, detalhes legais ou notas: Ex.: Valores sujeitos a alteração. Consulte condições.

Resumo final

  • <big> = obsoleto (evite)
  • Texto maior = CSS (font-size)
  • <small> = notas/observações (“letras miúdas”)

Mini-checklist

  • Eu removi <big> do meu código?
  • Eu usei CSS para tamanho?
  • <small> foi usado para nota, não para “deixar fofo”?

Perguntas rápidas

  1. Por que <big> não é recomendado?
  2. Qual é a alternativa moderna para aumentar fonte?

Texto excluído: <del>

<del> representa um trecho que foi removido do conteúdo. É perfeito para “antes e depois”, histórico de preço, changelog e revisão de texto.

Básico

Podemos marcar um texto como excluído para indicar que ele deve ser lido, mas não considerado.

Intermediário (exemplo real: preço e atualização)

Promoção: R$ 199 R$ 149 por tempo limitado.

Avançado (boas práticas)

  • Use com <ins> quando quiser mostrar substituição (tipo “controle de alterações”).
  • Você pode usar datetime (quando fizer sentido) para registrar quando a alteração aconteceu.

🔎 Exemplo (HTML para copiar)

<p>Promoção: <del>R$ 199</del> <strong>R$ 149</strong></p>

Resumo final

  • <del> = trecho removido
  • Ótimo para antes/depois e revisão
  • Combina bem com <ins>

Mini-checklist

  • Esse trecho foi realmente “removido” do conteúdo?
  • Preciso mostrar o texto novo com <ins>?

Texto inserido: <ins>

<ins> marca um trecho que foi adicionado. Ele é o “par perfeito” do <del> quando você quer mostrar mudanças.

Básico

Podemos marcar um texto inserido para dar ênfase e indicar que ele foi adicionado depois.

Intermediário (antes e depois em uma frase)

Meu objetivo é aprender dominar HTML e CSS.

Avançado (boas práticas)

  • Use <ins> quando você quer representar edição, não só “sublinhar bonito”.
  • Se for sublinhado por estilo, use CSS em um <span>.

🔎 Exemplo (HTML para copiar)

<p>Meu objetivo é <del>aprender</del> <ins>dominar</ins> HTML e CSS.</p>

Resumo final

  • <ins> = trecho adicionado
  • Use junto de <del> para mostrar revisão
  • Não use como “sublinhado decorativo”

Mini-checklist

  • Eu estou representando uma edição real?
  • Se for só estilo, devo usar CSS?

Perguntas rápidas

  1. Qual tag indica texto removido?
  2. Qual tag indica texto adicionado?

Sobrescrito e Subscrito: <sup> / <sub>

<sup> e <sub> são para motivos tipográficos (ex.: expoentes, notas de rodapé, fórmulas químicas). Eles são “de leve”, mas deixam o texto bem mais profissional.

Básico

Sobrescrito (SUP)

Exemplo: x20 + 3

Subscrito (SUB)

Exemplo: H2O

✅ Dica: sup/sub são ótimos para “detalhes pequenos” dentro do fluxo do texto: notas 1, m², fórmulas e expoentes.

Intermediário (exemplo com nota de rodapé)

Este texto tem uma nota1.
1 Exemplo didático: em projetos reais, você pode linkar a nota com âncoras.

Avançado (pegadinha comum)

⚠️ Atenção: para matemática pesada (frações, integrais, equações grandes), HTML puro fica limitado. Aí entram soluções específicas (ex.: renderização de fórmulas). Para o básico do dia a dia, <sup>/<sub> resolvem muito bem.

🔎 Exemplo (HTML para copiar)

<p>Expoente: x<sup>2</sup> + 10</p>
<p>Fórmula: H<sub>2</sub>O</p>
<p>Nota de rodapé<sup>1</sup></p>

Resumo final

  • <sup> = sobrescrito (expoente, nota)
  • <sub> = subscrito (fórmula, índice)
  • Use para tipografia, não para “enfeitar” texto

Mini-checklist

  • Estou usando sup/sub por motivo tipográfico real?
  • O texto continua legível em mobile?

Perguntas rápidas

  1. Qual tag você usaria para “m²”?
  2. Qual tag você usaria para “CO₂”?
