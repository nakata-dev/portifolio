Negrito: <b> vs <strong>

Nessa frase temos um termo em negrito usando a tag B (não semântica).

Já nesta outra frase aqui, temos um termo em negrito usando a tag STRONG (semântica).

Itálico: <i> vs <em>

Agora, neste outro caso temos um termo em itálico usando a tag I (não semântica).

Agora, nesta outra frase temos o termo ênfase usando o termo EM (semântica).

Texto marcado: <mark>

Podemos criar também um texto marcado usando a tag MARK.

Também podemos usar mark style para trocar a cor: marcação com outra cor.

Várias marcações com a mesma cor

Primeiro você deixa todos os textos marcado de amarelo básico.

Como eu vou fazer neste exemplo aqui.

Em seguida, na cabeça (HEAD) crie uma tag STYLE e personalize o mark.

<style>
  mark {
    background-color: limegreen;
  }
</style>
Assim o texto de todas as marcações ficará verde.

Texto grande e pequeno: <big> / <small>

Estamos criando um texto grande e um texto pequeno.

Observação: <big> é considerado obsoleto. Para “tamanho”, o ideal é usar CSS (font-size) e manter a semântica com HTML.

Texto excluído: <del>

Podemos marcar um texto como excluído para indicar que ele deve ser lido, mas não considerado.

Texto inserido: <ins>

Podemos marcar um texto inserido para dar ênfase e indicar que ele foi adicionado depois.
