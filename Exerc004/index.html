🌄 Tamanho de Imagens

Comparando versões de uma mesma imagem (650px, 1200px e original) e quando usar cada uma.

Voltar para HTML Contato

📍 Imagem reduzida (650px)

✅ Esta imagem foi redimensionada para 650px de largura no programa de edição. Ideal para carregar mais rápido (principalmente em mobile). 

<img src="paisagem-650.jpeg" alt="Paisagem 650px">

📍 Imagem média (1200px)

✅ Versão com 1200px de largura. Boa quando você precisa de mais qualidade visual sem pesar demais. 

<img src="paisagem-1200.jpeg" alt="Paisagem 1200px">

📍 Imagem original (full)

Dica prática: em sites reais, evite usar a imagem original enorme. Prefira uma versão otimizada (ex: 1200px ou 1600px), para não travar o carregamento.

✅ Aqui está a imagem no tamanho original. Geralmente usada para impressão ou quando é necessário muito detalhe.
