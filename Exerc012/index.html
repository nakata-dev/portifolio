Inserindo Vídeos

Três jeitos comuns: vídeo local (servidor próprio), YouTube e Vimeo, tudo responsivo.

Voltar para HTML Contato

1) Servidor próprio (HTML5)

Use <video> com múltiplos <source> para aumentar compatibilidade. Na prática, mp4 e webm já resolvem quase tudo.

Dica: vídeo local pesa no seu servidor. Se for conteúdo longo, YouTube/Vimeo costuma ser melhor.

2) Vídeo do YouTube (embed)

Vantagem: carrega rápido e não pesa no seu servidor. Desvantagem: depende da plataforma.

3) Vídeo do Vimeo (embed)

Observação: o script da API do Vimeo só é necessário se você for controlar o player via JavaScript.
