Colunas e Caixas

Como organizar conteúdo em colunas e criar caixas (cards) com boa leitura e responsividade.

Voltar para WordPress Contato

Visão geral

  • Colunas: dividem o layout em blocos (ex.: 2 colunas 50/50, 3 colunas 33/33/33).
  • Caixas: “cards” com fundo/borda/sombra para destacar um conteúdo.
  • Responsivo: no mobile, colunas geralmente viram 1 coluna (empilha).

Criando colunas

(Preencha aqui com o passo a passo do editor que você está usando: Gutenberg, Elementor, Astra, etc.)

  1. Adicionar bloco/section de colunas

    Ex.: “Adicionar → Colunas” e escolher a estrutura (2 ou 3 colunas).

  2. Definir proporções

    Ex.: 50/50, 70/30, 33/33/33.

  3. Ajustar espaçamentos

    Padding interno e gap entre colunas para dar respiro.

Criando caixas (cards)

A ideia da caixa é simples: colocar conteúdo dentro de um contêiner com fundo, borda e padding.

  • Fundo leve (ex.: cinza bem claro) para destacar sem pesar.
  • Padding consistente (ex.: 16–24px) para não “grudar”.
  • Borda/Sombra sutil (se usar) para separar do fundo.
  • Hierarquia: título curto + texto direto + botão (se tiver CTA).

Boas práticas (pra ficar profissional)

Regra de ouro: se está “confuso”, normalmente é falta de respiro (padding/gap) e excesso de elementos competindo pelo olhar.
  • Use no máximo 2–3 colunas no desktop (mais que isso vira formigueiro).
  • No mobile, prefira 1 coluna com espaçamento bom.
  • Mantenha padrão de bordas e raio iguais em todas as caixas.
  • Repetição é qualidade: mesmas margens, mesmos tamanhos, mesma linguagem.
