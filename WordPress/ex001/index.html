Instalando o WordPress (Local)

Passo a passo com XAMPP para treinar e desenvolver localmente.

Voltar para WordPress Contato

Guia rápido

  1. Abra o XAMPP

    Inicie o servidor local. Se Apache ou MySQL não abrirem, feche o software que está usando a mesma porta.

  2. Baixe o WordPress

    Faça o download no site oficial: Download WordPress.

  3. Coloque na pasta htdocs

    Cole o ZIP dentro de C:\xampp\htdocs, extraia e renomeie a pasta (ex.: cursowp).

  4. Acesse o phpMyAdmin

    No XAMPP, clique em Admin para abrir o painel.

  5. Acesse o projeto no navegador

    Troque http://localhost/dashboard/ por http://localhost/cursowp/.

  6. Configuração inicial

    Selecione o idioma Português (Brasil) e mantenha WordPress/Plugins atualizados.

  7. Defina as informações do site

    Preencha nome, usuário e senha. Dica: não marque “Visibilidade nos mecanismos de busca” no servidor local.

  8. Primeiro acesso ao painel

    Pronto. Agora você está em um ambiente local para treinar e desenvolver com WordPress.
