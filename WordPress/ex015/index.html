Como construir o topo do site com Astra do WordPress



Neste exercício, você aprenderá a construir o topo do site usando o tema Astra no WordPress. O Astra é um tema leve e altamente personalizável que facilita a criação de um site profissional. Siga os passos abaixo para configurar o topo do seu site:


1. Instale e ative o tema Astra no seu site WordPress. Vá para "Aparência" > "Temas" > "Adicionar Novo" e pesquise por "Astra". Clique em "Instalar" e depois em "Ativar".

2. Instale o plugin "Astra Starter Sites" para acessar modelos pré-construídos. Vá para "Plugins" > "Adicionar Novo" e pesquise por "Astra Starter Sites". Instale e ative o plugin.

3. Vá para "Aparência" > "Astra Sites" para explorar os modelos disponíveis. Escolha um modelo que tenha um topo que você goste e clique em "Importar Site".

4. Após a importação, vá para "Aparência" > "Personalizar" para personalizar o topo do seu site. Aqui você pode alterar o logotipo, o menu de navegação, as cores e outros elementos do topo.

5. Use o construtor de páginas (como Elementor ou Beaver Builder) para adicionar elementos adicionais ao topo, como botões de chamada para ação, barras de pesquisa ou ícones de redes sociais.

6. Salve suas alterações e visualize o site para ver como o topo ficou.
