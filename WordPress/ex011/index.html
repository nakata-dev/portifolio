Criando páginas

A base do menu é um conjunto de páginas bem nomeadas.

  1. Crie a página Home

    Vá em Páginas → Adicionar nova → crie a página Home → Publicar.

  2. Crie páginas essenciais

    Sugestão para um site “padrão profissional”: Home, Quem somos, Cardápio/Serviços, Notícias/Blog (opcional), Contato.

Criando o menu

Para criar um menu: Aparência → Menus.

  • Crie um menu chamado Menu Principal.
  • Adicione as páginas no menu (coluna da esquerda).
  • Organize a ordem arrastando e soltando.
  • Defina a posição do menu (ex.: Primary Menu / menu principal).
  • Salve.
Dica de conversão: deixe o menu com no máximo 5 a 6 itens. Menus enormes confundem e diminuem cliques no CTA.
