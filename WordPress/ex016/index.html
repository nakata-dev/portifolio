Rodapé Personalizado com Astra

Guia prático para criar rodapés no WordPress usando o construtor do tema Astra.

Voltar para WordPress Contato

Construtor de rodapé (Astra)

Com o tema Astra instalado e ativo no WordPress, vá em: Aparência → Personalizar → Rodapé → Construir rodapé.

  • Escolha o número de linhas e colunas para o rodapé.
  • Adicione blocos em cada área: Texto, Menus, Ícones sociais, etc.
  • Personalize o estilo e o layout conforme necessário.
  • Ao finalizar, clique em Publicar para salvar e aplicar no site.
Resumo: o Astra permite montar o rodapé como “peças”, definindo estrutura (linhas/colunas), conteúdo (blocos) e estilo (cores/tipografia).

Copyright no rodapé

Para exibir informações de copyright no rodapé usando Astra, a lógica é simples: você coloca um bloco de Texto no rodapé.

  1. Acesse o Personalizar

    No painel do WordPress: Aparência → Personalizar.

  2. Abra o construtor do rodapé

    Vá em Rodapé → Construir rodapé.

  3. Adicione um bloco de Texto

    Insira um bloco de Texto na área onde o copyright deve aparecer.

Rodapé personalizado via Widgets

Outra forma comum é usar Widgets dentro do personalizador, colocando um bloco de texto ou HTML na área do rodapé.

  1. Entre em Widgets

    No personalizador, clique em Widgets.

  2. Escolha a área do rodapé

    Selecione a área de rodapé onde o widget vai aparecer.

  3. Adicione Texto ou HTML Personalizado

    Insira um widget de Texto ou HTML Personalizado.

Configurações de estilo

Para ajustes finos como cores, tipografia e layout, explore as opções do personalizador do Astra.
