Erro de certificado (SSL) no WordPress local

Isso acontece quando você troca http por https no localhost sem ter um certificado válido.

Voltar para WordPress Contato

O que está acontecendo?

Quando você define o site como https em um ambiente local, o navegador tenta validar um certificado SSL. Como o localhost normalmente não possui certificado confiável, o acesso pode ser bloqueado, principalmente no painel (/wp-admin).

Meta: fazer o WordPress parar de forçar HTTPS no local e voltar para HTTP.

Como corrigir (passo a passo)

  1. Inicie Apache e MySQL

    Abra o XAMPP (ou WAMP/MAMP) e inicie os serviços Apache e MySQL.

  2. Acesse o phpMyAdmin

    Abra no navegador: http://localhost/phpmyadmin e selecione o banco do seu WordPress (ex.: cursowp).

  3. Abra a tabela wp_options

    Procure a tabela wp_options. Se você mudou o prefixo, pode ser algo como seuprefixo_options.

  4. Edite “siteurl” e “home”

    Localize os campos siteurl e home e troque: https://localhost/cursowp por http://localhost/cursowp. 

    option_name: siteurl   option_value: http://localhost/cursowp
option_name: home      option_value: http://localhost/cursowp
    Dica: se seu projeto tiver outro nome, substitua cursowp pelo nome correto.

  5. Teste o acesso

    Feche e reabra o navegador e acesse: http://localhost/cursowp/wp-admin/

Se tudo der certo

Quando usar HTTPS?

Em sites reais (hospedagem), você deve ter SSL ativo e usar HTTPS. Em localhost, só se configurar um certificado local (não obrigatório para treino).
