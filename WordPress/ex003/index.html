Instalando o WordPress Automaticamente

Instalador automático no painel da HostNet (mais rápido e prático).

Voltar para WordPress Contato

Passo a passo

  1. Acesse o instalador no painel

    Ao acessar o painel da HostNet, procure por Construtor de site / blog WordPress (ou seção de instaladores).

  2. Clique em instalar

    Clique em Instalar e selecione onde o WordPress será instalado (domínio/pasta).

  3. Configure domínio e pasta

    Se você tiver domínio próprio, preencha o campo Site. Se não quiser mudar o nome da pasta do WordPress, você pode instalar direto na pasta www.

  4. Defina banco de dados e senha

    Marque a opção de alteração e preencha os dados necessários:

    • Selecionar um banco de dados
    • Definir senha
    • Definir senha do aplicativo
    • Confirmar a senha do aplicativo
    • Clicar em Instalar

Importante: URL amigável (SEO)

Pesquise e aplique: como configurar URLs amigáveis no WordPress. Isso ajuda o site a ficar melhor posicionado no Google.

Depois de instalado

Você terá acesso a opções como: Acessar, Administração, Desinstalar, Alterar Senha, Alterar Dados de Configuração, Configurar Domínio.

Normalmente, no instalador automático da HostNet, vários plugins essenciais já vêm instalados e configurados.
