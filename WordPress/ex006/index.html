O que é o Painel de Controle?

O painel do WordPress é a interface administrativa onde você gerencia tudo: páginas e posts, aparência, menus, plugins, usuários e configurações.

Link útil: Comunidade HostNet (WordPress)

Como é o painel?

Menu dinâmico

O Menu Dinâmico facilita o acesso rápido às funcionalidades do WordPress. É uma forma de navegar com mais agilidade no admin.

Personalizar

O menu Personalizar é usado para ajustar visual do tema: cores, tipografia, identidade e alguns componentes do layout (dependendo do tema).

Dica: quando estiver criando site para cliente, defina primeiro: paleta, fontes, hierarquia e espaçamentos. A estética fica consistente e “de agência”.

Menu geral

No menu lateral você encontra as áreas principais para administrar o site.

A tela “Painel” (Visão geral)

A tela do Painel mostra uma visão rápida do status do site: avisos de atualização, rascunhos, atalhos e outros widgets informativos.

Recomendação: explore o menu com calma. Entender onde cada coisa fica deixa você muito mais rápido na produção de sites.
