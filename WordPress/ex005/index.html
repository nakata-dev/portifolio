Alterando http para https

Atenção: Configuração válida somente para servidor privado

Para alterar o protocolo de http para https em seu site WordPress, siga os passos abaixo:


  1. Faça backup do seu site.
  2. Atualize a URL do WordPress e a URL do Site nas configurações gerais.
  3. Instale um plugin de SSL, como o Really Simple SSL.
  4. Verifique se todos os links internos estão usando https.
  5. Teste seu site para garantir que tudo está funcionando corretamente.

Essas configurações são essenciais para garantir que seu site WordPress funcione corretamente com HTTPS.

Configurando o WPS Hide Login

Para proteger seu site WordPress de possíveis ataques de robôs, você pode seguir estas dicas:


1º Ative WPS Hide Login


2º Acessa Configurações > WPS Hide Login


3º Altere a palavra do Campo URL de "login" para "palavra_de_sua_preferencia".


Clique em salvar alterações.


O importante é dificultar ao máximo o acesso de login contra invasões indesejadas.


Agora, quando você tentar acessar (http://localhost/cursowp/login/) vai aparecer uma página de erro 404.


Isso significa que a URL de login foi alterada com sucesso.

Para isso que serve o plugin WPS Hide Login.


Altere a palavra do URL de acesso:"login" para "******" e obtenha o acesso ao endereço.
é assim que você vai conseguir se proteger minimamente de ataques de robôs maliciosos. Os famosos Crakers.
