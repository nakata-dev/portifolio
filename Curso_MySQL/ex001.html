Conceitos essenciais de Banco de Dados

Pense em um banco de dados como um lugar onde você guarda informações organizadas. Ele funciona como um armário com gavetas: cada gaveta tem um tipo de coisa, e tudo fica fácil de encontrar.

Containers diferentes para características diferentes

Registros, Tabelas e Banco de Dados

A ideia central: um banco guarda tabelas, e tabelas guardam registros (linhas).

Informações dentro de uma tabela

Toda tabela tem campos (colunas) e registros (linhas).

Tipos primitivos no MySQL

Tipos são como “formatos” que definem o que pode ser guardado (texto, número, data…).

Dica: escolher o tipo correto economiza espaço e evita erros na hora de cadastrar dados.

Crie a sua primeira tabela

Agora sim: no seu MySQL, crie a tabela pessoas com os campos abaixo. 

create table pessoas(
Nome varchar(30),
Idade tinyint,
Sexo char(1),
peso float,
altura float,
nacionalidade varchar(20)
);

describe pessoas;

Sem chave primária...

Quando não existe chave primária, você pode repetir registros sem controle. Isso gera bagunça no banco.

Tradução prática: uma chave primária é como um “RG único” dentro da tabela ✅
