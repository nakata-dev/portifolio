DISTINCT, GROUP BY e HAVING

Pense no GROUP BY como “juntar em pacotes”. E o HAVING como “filtrar esses pacotes” ✅

Agrupar dados (GROUP BY)

Exemplo: agrupar cursos pela carga horária. 

select carga
from cursos
group by carga;
Voltar
O que acontece: o resultado mostra apenas as cargas únicas existentes ✅

Resultado (exemplo)

Agregando + Agrupando (COUNT + GROUP BY)

Aqui você descobre quantos cursos possuem a mesma quantidade de aulas. 

select aulas, count(*) as total
from cursos
group by aulas
order by aulas;

-- Exemplo: ver quais cursos têm 30 aulas
select * from cursos
where aulas = 30;
Voltar
Dica: count(*) conta quantas linhas existem em cada grupo ✅

HAVING (filtrar grupos)

O WHERE filtra linhas antes de agrupar. O HAVING filtra depois de agrupar. 

select ano, count(*) as total
from cursos
group by ano
having ano > 2020
order by total asc;
Voltar
Tradução: “mostre apenas os anos acima de 2020” ✅

Revisando AVG (média)

Para descobrir a média de carga horária de todos os cursos: 

select avg(carga) as media_carga
from cursos;
Voltar

Agrupando e filtrando acima da média

Esse aqui é forte: você filtra os grupos comparando com o resultado de outro SELECT. 

select carga, count(*) as total
from cursos
where ano > 2020
group by carga
having carga > (select avg(carga) from cursos);
Voltar
Resumo: selecionei + filtrei + agrupei + mostrei só o que ficou acima da média ✅
