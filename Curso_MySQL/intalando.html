Instalação no Windows (WampServer + MySQL)

No Windows, uma forma prática de montar um ambiente local é usar o WampServer, que instala de uma vez só o necessário para rodar serviços como Apache e MySQL.

WampServer

Objetivo: instalar os programas na ordem certa para evitar erros no Wamp.

1º Passo - Baixe e instale nessa ordem

  1. Framework
  2. C++ Visual Studio 2010
  3. C++ Visual Studio 2012
  4. MySQL Workbench 6.3.6

2º Passo - Instale o WampServer

  • Download WampServer (site oficial)

3º Passo - Instale o XAMPP (somente se precisar)

  • Download XAMPP (Apache Friends)
Atenção: Use o XAMPP somente se você não conseguir instalar corretamente o WampServer.
