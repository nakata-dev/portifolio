Consultas essenciais no MySQL

Vamos criar um banco do zero, inserir 50 registros e praticar consultas como gente grande ✅

1º Passo: Criar database e tabela

Para facilitar suas consultas, vamos criar a tabela com os campos certinhos (curso, instrutor, carga, aulas e ano). 

create database escola_cursos;
use escola_cursos;

create table cursos (
  idcurso int auto_increment primary key,
  curso varchar(100),
  instrutor varchar(100),
  carga int,
  aulas int,
  ano year
);

ORDER BY (organizando resultados)

Em bancos grandes, ordenar faz MUITA diferença para enxergar padrões. 

select * from cursos
order by instrutor desc;

-- ou

select * from cursos
order by curso desc;
Voltar

Selecionar apenas alguns campos

Você não precisa puxar tudo. Pode consultar só o que interessa. 

select curso, carga
from cursos;
Voltar

WHERE (filtrando resultados)

O WHERE funciona como “enquanto” ou “somente quando”. 

select ano, curso
from cursos
where ano = 2020
order by curso asc;

-- ordem descendente (Z-A)
select ano, curso
from cursos
where ano = 2020
order by curso desc;
Voltar
Dica: ASC = crescente | DESC = decrescente ✅

Selecionando linhas e colunas (ano <= 2022)

select instrutor, curso, ano
from cursos
where ano <= 2022
order by instrutor desc;
Voltar

BETWEEN (faixa de valores)

Seleciona tudo que estiver “entre” dois valores. 

select instrutor, ano
from cursos
where ano between 2020 and 2024
order by ano desc, instrutor asc;
Voltar

IN (valores específicos)

Perfeito quando você quer “somente estes anos aqui”. 

select instrutor, curso, ano
from cursos
where ano in (2019, 2023, 2025)
order by ano asc;
Voltar

Operador lógico AND

O AND exige que as duas condições sejam verdadeiras. 

select instrutor, carga, aulas
from cursos
where carga > 35 and aulas < 30;

describe cursos;
Voltar

Operador lógico OR

O OR aceita “uma condição ou outra”. 

select instrutor, carga, aulas
from cursos
where carga > 35 or aulas < 30;

describe cursos;
