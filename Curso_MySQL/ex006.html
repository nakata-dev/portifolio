Fazendo Backup

por: Ailton A. Nakata

Gerenciando Cópias de Segurança MySQL:

1º abra o cadastro e selecione o cursos

    
use cadastro;

select*from cursos;
select*from gafanhotos;
describe gafanhotos;
desc gafanhotos;
desc cursos;

2º Click em menu server

3º Selecione Data Export

4º Selecione Cadastro

5º Selecione tudo o que você quer salvar dentro do Schema Objects

6º Click em Dump Structure and Data

7º Escolha um local onde deseja salvar o arquivo e pressione Start Export

Não esqueça de marcar a opção Export to Self-contained file, que vai fazer com que todos os dados sejam salvos em um arquivo único.

Agora para ver se funciona, é hora de apagar o cadastro:

    
drop database cadastro;

Para importar seu banco de dados, basta fazer o caminhor reverso:

1º server > Data Import

2º pressione em Star Import
