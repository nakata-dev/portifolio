Operador Like A% :

    
select*from cursos
where nome like a%;

like : significa parecido e (%) significa nenhum ou vários caracteres


Mudando o %A de lugar:

    
select*from cursos
where nome like %a;

Like %A%:

        
select*from cursos
where nome like %a%;

Vai pegar qualquer coisa que estiver antes do a e depois, e isso inclui o A. Dando preferênci para pegar o A que também se encontra no meio da palavra.

Like ph%p%:

    
select*from cursos 
where curso not like 'ph%p%';

Like %silva%:

    
select*from cursos 
where nome not like '%silva%';

Quero um nome que tenha a palavra 'silva' em qualquer lugar do nome.


Distinguindo:

    
select*from cursos;

select distinct curso from carga
order by carga;

Funções de agregações:

    
select(*)from cursos where carga > 40;

Função max(nome)

    
select*from cursos where ano='2020';

quando quiser saber qual é o curso com maior quantidade de aulas de 2016:

select max(aula) from cursos where ano = '2020'

Função sum ou soma:

    
select*from cursos where ano = '2018';        
select sum(totaulas) from cursos where ano=2018;

Função avg ou média:

    
select*from cursos where ano = '2019';
select avg(totaulas) from cursos where ano='2019';

A média(avg) total de aulas de 2019 será de 28.7500
