Filtros por texto e agregações

O LIKE é perfeito para buscar textos parecidos. E as funções de agregação ajudam a contar, somar, tirar média e achar máximos.

Operador LIKE: 'A%'

Significa: começa com A. O símbolo % vale “nenhum ou vários caracteres”. 

select * from cursos
where curso like 'A%';
Voltar
Resumo: LIKE = parecido | % = vários caracteres ✅

Mudando o % de lugar: '%a'

Agora significa: termina com a. 

select * from cursos
where curso like '%a';
Voltar

LIKE '%a%'

Aqui ele pega qualquer coisa que tenha a letra a em qualquer posição. 

select * from cursos
where curso like '%a%';
Voltar
Entenda: %a% procura o "a" no começo, meio ou fim ✅

NOT LIKE 'ph%p%'

O NOT LIKE faz o contrário: ele ignora padrões. 

select * from cursos
where curso not like 'ph%p%';
Voltar

NOT LIKE '%silva%'

Aqui ele exclui qualquer instrutor que tenha "Silva" no nome. 

select * from cursos
where instrutor not like '%silva%';
Voltar
Explicação: ele remove resultados que contenham a palavra silva em qualquer lugar ✅

DISTINCT (tirando repetidos)

O DISTINCT mostra apenas valores únicos (sem repetição). 

select distinct carga
from cursos
order by carga;
Voltar

Funções de agregação: COUNT

O COUNT conta quantos registros batem com a condição. 

select count(*)
from cursos
where carga > 40;
Voltar

MAX (maior valor)

Exemplo: descobrir o curso com maior quantidade de aulas em um ano específico. 

select * from cursos
where ano = 2020;

-- Maior número de aulas em 2020:
select max(aulas)
from cursos
where ano = 2020;
Voltar

SUM (soma)

Soma os valores de uma coluna (ex: total de aulas em um ano). 

select * from cursos
where ano = 2018;

select sum(aulas)
from cursos
where ano = 2018;
Voltar

AVG (média)

Faz a média dos valores de uma coluna em um filtro. 

select * from cursos
where ano = 2019;

select avg(aulas)
from cursos
where ano = 2019;
Voltar
Observação: o AVG pode retornar casas decimais (ex: 28.7500) ✅
