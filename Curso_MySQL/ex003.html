Insert Into

Nesta aula você aprende a inserir dados na tabela usando INSERT INTO, visualizar com SELECT e usar DEFAULT para simplificar.

Inserindo dados na tabela

O comando INSERT INTO serve para adicionar novos registros em uma tabela. A estrutura básica é: tabela + campos + valores.

Situação I: Criando orientação

Inserção completa informando os campos. 

insert into pessoas
(id, nome, nascimento, sexo, peso, altura, nacionalidade)
values
(1, 'Godofredo', '1984-01-02', 'M', 78.5, 1.75, 'Brasil');
Voltar
Dica: no MySQL, o comando correto é values (no plural) ✅

Situação II: Mostrar cadastro de pessoas

Após inserir, você pode listar com SELECT. 

insert into pessoas
(id, nome, nascimento, sexo, peso, altura, nacionalidade)
values
(1, 'Godofredo', '1984-01-02', 'M', 78.5, 1.75, 'Brasil');

select * from pessoas;
Voltar

Situação III: Usando o DEFAULT

Quando um campo tem valor padrão, você pode usar DEFAULT. 

insert into pessoas
(id, nome, nascimento, sexo, peso, altura, nacionalidade)
values
(default, 'Godofredo', '1984-01-02', 'M', 78.5, 1.75, default);

select * from pessoas;
Voltar
Exemplo clássico: usar default no ID (auto incremento) e no país (Brasil) ✅

Situação IV: Como a ordem é a mesma, simplifique!

Se você seguir exatamente a ordem dos campos da tabela, pode inserir sem informar os nomes. 

insert into pessoas values
(default, 'Bianca', '2003-11-22', 'F', 78.5, 1.75, 'Inglaterra');

select * from pessoas;
Voltar
Cuidado: se mudar a estrutura da tabela, essa forma pode dar erro ou inserir no campo errado.

Situação V: Inserindo vários registros de uma vez

Você pode inserir múltiplas pessoas no mesmo comando usando vírgula entre os grupos de valores. 

insert into pessoas (id, nome, nascimento, sexo, peso, altura, nacionalidade)
values
(default, 'Bianca', '2002-09-22', 'F', 56.1, 1.55, 'Inglaterra'),
(default, 'Eliza', '1995-06-19', 'F', 78.5, 1.75, 'Irlanda'),
(default, 'Marcos', '1932-10-18', 'M', 71.3, 1.68, 'Japão'),
(default, 'Gisele', '1999-11-10', 'F', 60.8, 1.55, 'America');

select * from pessoas;
Voltar
Dica: perceba que cada linha termina com , e a última termina com ; ✅
