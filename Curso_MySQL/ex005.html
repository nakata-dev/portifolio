Modificando o conteúdo da linha:

    
update cursos
set nome = 'HTML5'
where idcurso = '1';

select&from cursos;

Onde era HTML4 é alterado para HTML5

Outra alteração:

    
update cursos
set nome = 'php', ano = '2015' 
where idcurso = '4';

select&from cursos;

Alterando configurações de workbench:

    
acesse o menu Edit > Preference > SQL editor
desmarque safe update(Reject update and deletes with no restrictions)

Vamos supor que desejamos alterar agora três linhas de uma só vez:

Veja como fica no código:


    
up date cursos
set ano = '2050', carga = '800'
where ano = '2018';


select*from cursos;

where ano = '2018' = Enquanto ano for 2018. Isso vai funcionar caso você já tenha feito a alteração na configuração de seguraça do workbench.

Por recomendação do professor Gustavo Guanabara, é importante sempre deixar ligado o sitema de seguraça do workbench.

Comando para deletar linhas:

    
delete from cursos
where idcurso='8';       

select*from cursos;

Caso queira apagar dois cursos de uma vez, use o comando (limit):

    
delete from cursos
where ano='2050'

limit 2;

select*from cursos;

Apagando todas a linhas de uma tabela com o comando (Truncate):

    
truncate cursos;

select*from cursos;
