Update, Delete e Truncate

Nesta aula você aprende a atualizar, deletar e limpar registros no MySQL com segurança usando WHERE e LIMIT.

Manipulando dados na tabela cursos

Aqui entram os comandos DML: INSERT, UPDATE, DELETE e TRUNCATE. Eles mexem diretamente nos registros (linhas) da tabela.

Inserindo dados

Vamos popular a tabela cursos com vários registros de uma vez. 

insert into cursos values
(1, 'HTML4', 'Curso de HTML5', 40, 37, 2024),
(2, 'Algoritmos', 'Lógica de programação', 20, 15, 2014),
(3, 'Photoshop', 'Dicas de Photoshop CS', 10, 8, 2014),
(4, 'PHP', 'Curso de PHP para iniciantes', 40, 20, 2010),
(5, 'Java', 'Introdução a linguagem JAVA', 10, 29, 2000),
(6, 'MySQL', 'Banco de Dados MySQL', 30, 15, 2016),
(7, 'Word', 'Curso completo de WORD', 40, 30, 2016),
(8, 'Sapateado', 'Dança rítmica', 40, 30, 2018),
(9, 'Cozinha Árabe', 'Aprenda a fazer Kibe', 40, 30, 2018),
(10, 'YouTuber', 'Gerar polêmica e ganhar inscritos', 5, 2, 2018);

select * from cursos;
Voltar
Dica: números podem ficar sem aspas (fica mais correto e evita confusão).

Veja como fica a tabela

Modificando o conteúdo da linha

O UPDATE altera dados existentes. Sempre use WHERE para não atualizar tudo sem querer. 

update cursos
set nome = 'HTML5'
where idcurso = 1;

select * from cursos;
Voltar
Resultado: onde era HTML4 será alterado para HTML5.

Outra alteração (mais de um campo)

Você pode atualizar vários campos no mesmo update. 

update cursos
set nome = 'PHP', ano = 2015
where idcurso = 4;

select * from cursos;
Voltar

Alterando configurações do Workbench (Safe Updates)

Acesse o menu: Edit > Preferences > SQL Editor
Desmarque: "Safe Updates (Reject updates and deletes with no restrictions)"
Voltar
Recomendação: use isso apenas quando necessário. O Safe Updates ajuda a evitar acidentes 😅

Alterando várias linhas de uma só vez

Se você usar um WHERE mais amplo (ex: ano = 2018), ele altera várias linhas ao mesmo tempo. 

update cursos
set ano = 2050, carga = 800
where ano = 2018;

select * from cursos;
Voltar
Explicação: where ano = 2018 significa: altere todo registro que estiver com ano 2018.
Dica do Guanabara: deixe o Safe Updates ligado na maior parte do tempo ✅

Comando para deletar linhas (DELETE)

O DELETE remove registros. Use WHERE para deletar apenas o que você quer. 

delete from cursos
where idcurso = 8;

select * from cursos;
Voltar

Apagando mais de um registro com LIMIT

Se quiser limitar quantas linhas serão apagadas, use LIMIT. 

delete from cursos
where ano = 2050
limit 2;

select * from cursos;
Voltar
Importante: LIMIT é útil para evitar apagar “coisa demais” por engano ✅

Apagando todas as linhas com TRUNCATE

O TRUNCATE limpa todos os registros da tabela de uma vez (mais rápido e direto). 

truncate table cursos;

select * from cursos;
Voltar
Na prática: TRUNCATE = “esvaziar a tabela inteira” 🧹
