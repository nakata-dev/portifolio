Acessando Console e PHPMyAdmin pelo WampServer

O PHPMyAdmin é uma forma visual de administrar o MySQL pelo navegador. Já o MySQL Console é o modo “raiz”: comandos direto no terminal.

MySQL Console

Aqui você consegue executar os comandos igual no Workbench, mas usando terminal. 

1º Abra o programa WampServer64 e clique no ícone.
2º Vá em: MySQL > MySQL Console
3º No Console você pode executar todos os comandos que usou no Workbench.

Dica: pratique usando as 3 formas:
- Workbench
- Console
- PHPMyAdmin
