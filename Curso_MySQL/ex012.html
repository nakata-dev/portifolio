ACID

Conjunto de regras que garantem segurança e consistência em transações.

Relacionamento 1 para muitos (1:N)

Adicionando o campo cursopreferido

Vamos criar a coluna que vai receber o ID do curso preferido do gafanhoto. 

use cadastro;

desc gafanhotos;

alter table gafanhotos
add column cursopreferido int;
Voltar

Transformando em chave estrangeira

Aqui você informa ao MySQL que esse campo aponta para a tabela cursos. 

alter table gafanhotos
add foreign key (cursopreferido)
references cursos(idcurso);

desc gafanhotos;
Voltar

Leitura em linguagem natural

update gafanhotos
set cursopreferido = 6
where id = 1;
Voltar
Tradução: “Atualize a tabela gafanhotos, mude o valor de cursopreferido para 6, mas somente no registro onde o id é igual a 1.”

Também dá pra fazer isso manualmente pelo grid do Workbench (embaixo da área de comandos).

Integridade referencial

Se um curso está sendo usado por alguém, você não pode apagar ele do nada. 

-- Tentando deletar um curso que está relacionado:
delete from cursos
where idcurso = 6;

-- Esse delete pode falhar se existir gafanhoto com cursopreferido = 6
Voltar

Apagando um curso sem relacionamento

delete from cursos
where idcurso = 28;

select * from cursos;

-- Exemplo: escolhi 28 porque ele não estava ligado em cursopreferido
Voltar

JOIN e ON

Aqui você “cola” uma tabela na outra usando a chave estrangeira como ponte. 

select gafanhotos.nome, cursos.curso, cursos.ano
from gafanhotos join cursos
on cursos.idcurso = gafanhotos.cursopreferido;
Voltar
O que significa: selecione o nome do gafanhoto, o nome do curso e o ano, criando a relação com ON.

INNER JOIN com abreviações

Abreviações ajudam bastante em consultas grandes. 

select g.nome, c.curso, c.ano
from gafanhotos as g
inner join cursos as c
on c.idcurso = g.cursopreferido
order by g.nome;
Voltar
Observação: o que vem depois do ponto não pode ser abreviado. Ex: c.idcurso ✅

LEFT OUTER JOIN (prioriza a tabela da esquerda)

select g.nome, c.curso, c.ano
from gafanhotos as g
left outer join cursos as c
on c.idcurso = g.cursopreferido
order by g.nome;
Voltar

RIGHT OUTER JOIN (prioriza a tabela da direita)

select g.nome, c.curso, c.ano
from gafanhotos as g
right outer join cursos as c
on c.idcurso = g.cursopreferido
order by g.nome;
