Alter table e Drop table

por: Ailton A. Nakata

ALTER TABLE

            
desc pessoas;
alter tablet pessoas
add column profisao varchar(10);

select*from pessoas;

alter table serve para adicionar uma coluna à tabela

DROP TABLE

            
desc pessoas;
drop tablet pessoas


select*from pessoas;

alter table serve para retirar uma coluna da tabela

Escolha nova posição da coluna (profissao)

            
desc pessoas;
alter table pessoas
add column profissao varchar(10) after nome;


select*from pessoas;

add column serve para adicionar uma coluna em uma posição especifica.

Mais uma alteração (codigo)

            
desc pessoas;
alter table pessoas
add column codigo int firt;


select*from pessoas;

Aqui a coluna codigo vai ser inserida no ínicio.

E quando eu quero alterar alguma característica da coluna?

            
desc pessoas;
alter table pessoas
Modify column profissao varchar(20) not null default '';


select*from pessoas;

Neste caso o campo profissão vai ficar vazio, pois foi alterado para not null ou seja, não pode ficar nulo.

Note como o campo profissão ficou sem nada ao acrescentarmos o comando (default ' ')

Comando change:

            
desc pessoas;
alter table pessoas
change column profissao prof varchar(20);

select*from pessoas;

Aqui o comando change modifica o tipo, constraint e nome da coluna.

Renomeando a tabela inteira:

            
desc pessoas;
alter table pessoas
rename to gafanhotos;

select*from pessoas;

Aqui o comando rename to foi responsável para alterar o nome da tabela pessoas para gafanhotos.

Criando uma nova tabela:

    
create table if not exists cursos(
Nome varchar(30) not null unique,
descricao text,
carga int unsigned,
totalaula int unsigned,
ano year default '2025'    
) charset = utf8;   

alter table cursos
add column idcurso int first;

describe cursos;

Alterando a chave primaria:

    
create table if not exists cursos(
Nome varchar(30) not null unique,
descricao text,
carga int unsigned,
totalaula int unsigned,
ano year default '2025'    
) charset = utf8;   

alter table cursos
add primary key(idcurso);

describe cursos;
