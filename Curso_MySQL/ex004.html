ALTER TABLE e DROP TABLE

Aprenda como modificar a estrutura de tabelas no MySQL: adicionar colunas, ajustar posição, alterar campos, renomear e apagar tabelas.

Voltar para Estudos Contato

Mudando a estrutura de uma tabela

O ALTER TABLE altera a estrutura da tabela (colunas, tipos, constraints...). Já o DROP TABLE apaga a tabela inteira.

ALTER TABLE (adicionar coluna)

Aqui você adiciona a coluna profissao na tabela pessoas. 

desc pessoas;

alter table pessoas
add column profissao varchar(10);

select * from pessoas;
Voltar
Resumo: alter table serve para adicionar ou alterar colunas.

DROP TABLE (apagar a tabela)

Esse comando remove a tabela inteira (cuidado!). 

desc pessoas;

drop table pessoas;
Voltar
Atenção: drop table apaga a tabela e os dados junto. Não tem Ctrl+Z 😅

Escolhendo a posição da coluna (AFTER)

Você pode escolher onde a coluna vai aparecer usando after. 

desc pessoas;

alter table pessoas
add column profissao varchar(10) after nome;

select * from pessoas;
Voltar
Resumo: add column + after posiciona a coluna após um campo específico ✅

Inserindo no início (FIRST)

Se você quer colocar uma coluna no começo, use first. 

desc pessoas;

alter table pessoas
add column codigo int first;

select * from pessoas;
Voltar

MODIFY (alterar características da coluna)

O modify muda o tipo e as constraints de uma coluna, mantendo o nome. 

desc pessoas;

alter table pessoas
modify column profissao varchar(20) not null default '';

select * from pessoas;
Voltar
Entenda: como a coluna virou not null, o banco preenche com o default '' (vazio).

CHANGE (trocar nome + tipo)

O change permite trocar o nome da coluna e também o tipo/constraints. 

desc pessoas;

alter table pessoas
change column profissao prof varchar(20);

select * from pessoas;
Voltar
Resumo: change altera nome + tipo + regras da coluna ✅

Renomeando a tabela inteira

Você pode trocar o nome da tabela com rename to. 

desc pessoas;

alter table pessoas
rename to gafanhotos;
Voltar
Importante: depois disso, você acessa a tabela pelo novo nome: gafanhotos.

Criando uma nova tabela: cursos

Exemplo criando uma tabela do zero e depois adicionando o ID no início. 

create table if not exists cursos(
nome varchar(30) not null unique,
descricao text,
carga int unsigned,
totalaulas int unsigned,
ano year default '2025'
) default charset = utf8;

alter table cursos
add column idcurso int first;

describe cursos;
Voltar

Alterando a chave primária

Aqui você adiciona a chave primária no campo idcurso. 

alter table cursos
add primary key(idcurso);

describe cursos;
Voltar
Dica: chave primária = identificador único da tabela ✅
