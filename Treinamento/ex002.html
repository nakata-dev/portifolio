COMO FAZER O BOTÃO GIRAR?


Para você conseguir fazer o botão girar, use o @keyframes (nome do movimento).

No exemplo acima, o nome do movimento é "girar".

Depois, dentro do hover do botão, chame a animação com o nome que você definiu no @keyframes.

Exemplo: animation: girar 0.8s ease-in-out reverse; <

O importante aqui, é você praticar para poder compreender a fundo cada detalhe, só assim conseguira aprender verdadeiramente cada coisa.
