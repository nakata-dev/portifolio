O uso do iFrame

Objetivo: incorporar páginas (locais ou externas) e navegar entre conteúdos sem abrir várias abas.

Abaixo temos exemplos claros de como inserir um iFrame e controlar seu tamanho via CSS. No primeiro exemplo, carregamos um conteúdo local (página na mesma pasta).

Agora, outro exemplo com link local (você busca o caminho direto dentro da mesma pasta do projeto).

Nesta situação, incorporamos uma tabela responsiva. Isso é útil quando o cliente quer mostrar uma informação (ex: vendas) sem fazer o usuário ficar abrindo várias páginas.

Resumo (situações)

Situação 01: inserir uma página local dentro do seu site principal poupa tempo do usuário.

Situação 02: abrir tabelas e conteúdos “pesados” dentro de um espaço controlado melhora a navegação, principalmente no mobile.

Como navegar através de um iFrame?

Para navegar dentro de um iFrame, você cria uma lista de links e define o target deles para o mesmo valor do atributo name do iFrame. Assim, cada clique troca o conteúdo carregado dentro do quadro.

Regra de ouro: target do link deve ser igual ao name do iFrame.

Escolha uma opção (navegação 1)

  • Iframe
  • Teste
  • Responsivo
<h2>Escolha uma opção:</h2> <ul> <li><a href="iframe.html" target="frame1">Iframe</a></li> <li><a href="teste.html" target="frame1">Teste</a></li> <li><a href="tabela_responsiva.html" target="frame1">Responsivo</a></li> </ul> <iframe name="frame1"></iframe>

Usando srcdoc (conteúdo inicial)

Também é possível carregar um conteúdo inicial com srcdoc, antes do usuário escolher um link. Isso é ótimo para instruções, boas-vindas ou um “placeholder” bonito.

  • Primeira página
  • Segunda página
  • Terceira página
<iframe name="frame2" srcdoc="<h1>Escolha uma das opções acima</h1> <p>Conteúdo inicial...</p>"> </iframe>

Atenção: o name do iFrame precisa ser o mesmo que você usa no target dos links, senão a navegação não funciona.
