Comandos de Segurança em iFrames

Protegendo embeds com sandbox e referrerpolicy.

Voltar para HTML

O que é o sandbox?

Ideia: sandbox “tranca” o iFrame. Você só libera o que for necessário (com allow-*).

Quando você incorpora uma página em um iFrame, ela pode tentar executar scripts, enviar formulários, abrir popups, acessar recursos, etc. O atributo sandbox reduz esses riscos aplicando restrições por padrão.

Exemplo 1: sandbox total (mais restrito)
<iframe src="formulario.html" sandbox> Seu navegador não é compatível com isso! </iframe>

Aqui o iFrame fica bem “travado”. Ideal quando você só quer exibir algo simples e estático.

Exemplo 2: sem referrer (privacidade)
<iframe src="formulario.html" sandbox referrerpolicy="no-referrer"> </iframe>

referrerpolicy="no-referrer" evita que o destino receba informações de “de onde você veio”.

Exemplo 3: liberando o mínimo necessário

Se você precisa de formulário e scripts (por exemplo, validação), libere só o que for necessário. Atenção: allow-same-origin torna o conteúdo do iFrame menos isolado, então use com consciência.

<iframe src="formulario.html" sandbox="allow-forms allow-scripts" referrerpolicy="no-referrer"> </iframe>

Dica: se não precisar, evite allow-same-origin. Libere só forms/scripts quando realmente necessário.

Usando JavaScript com mais segurança

Abaixo, carregamos iframe5.html permitindo scripts. Isso é útil quando você controla o conteúdo incorporado, mas ainda quer manter algumas barreiras.

<iframe src="iframe5.html" sandbox="allow-scripts" referrerpolicy="no-referrer"> </iframe>

allow-scripts: permite execução de JavaScript dentro do iFrame.
referrerpolicy="no-referrer": não envia dados de referência para o destino.
