Exemplo de iFrame

Objetivo: ver um conteúdo carregando dentro do “retângulo” do iFrame, sem sair da página.

Dica: no mobile, você pode rolar dentro do iFrame e também rolar a página.

Como usar o iFrame?

iFrame: é um “quadro” que permite incorporar uma página dentro de outra, como uma janela embutida. Estrutura básica:

<iframe src="https://nakata-dev.github.io/portifolio"> Seu navegador não suporta iFrame. <a href="https://nakata-dev.github.io/portifolio" target="_blank" rel="noopener noreferrer"> Abrir em nova aba </a> </iframe>

O tamanho padrão de um iFrame é aproximadamente 300×150 pixels (pode variar conforme CSS do navegador). Situação 2: dentro do iFrame você pode colocar uma mensagem opcional ou até um link opcional (fallback), para abrir o conteúdo em nova aba. Situação 3: no CSS você controla altura, largura, borda, raio e responsividade. Exemplo:

iframe{ width: 100%; max-width: 720px; height: 340px; border: 1px dashed rgba(0,0,0,0.45); border-radius: 14px; }
