Como capturar fontes em sites

  1. Acesse a Chrome Web Store .
  2. Procure e adicione a extensão Fonts Ninja.
  3. Ative a extensão e passe o mouse sobre textos de um site para ver as fontes usadas.

Clique na imagem para abrir a extensão.

Como capturar fontes em imagens

Use os sites abaixo para identificar fontes a partir de uma imagem (ex.: print, logo, banner).

  • MyFonts: WhatTheFont ↗
  • WhatFontIs ↗
Dica: recorte a imagem deixando só o texto e aumente o contraste antes de enviar.
