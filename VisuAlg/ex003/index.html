A soma de dois números

VisuAlg: lendo duas entradas e exibindo a soma no final.

Voltar para VisuAlg Contato

Operadores e soma

  • leia: recebe o valor digitado pelo usuário.
  • Variáveis inteiras: n1, n2 e s.
  • Operador +: soma os valores e guarda o resultado em s.
algoritmo "Soma de dois números"
// Função :Somar dois números inteiros
// Autor :Ailton A. Nakata
// Data : 05/11/2024
// Seção de Declarações 
var
   n1, n2, s : inteiro
inicio
// Seção de Comandos 
   escreva ("Informe um número: ")
   leia(n1)
   escreva ("Informe outro número: ")
   leia(n2)
   s <- n1 + n2
   escreva ("O soma entre ", n1, " e", n2, " é igual a ", s)
