Empréstimo

VisuAlg: calcular o valor de cada parcela com acréscimo de 20%.

Voltar para VisuAlg Contato

Como o cálculo é feito

  • Lê o valor do empréstimo.
  • Lê em quantas parcelas vai pagar.
  • Calcula 20% do valor: porcentagem ← (emprestimo × 20) / 100.
  • Soma e divide pelas parcelas: valorfinal ← (emprestimo + porcentagem) / parcelas.
algoritmo "Empréstimo"
// Função : Algoritmo para calcular 20% a mais em cada parcela do pagamento do empréstimo
// Autor :Ailton A. Nakata
// Data : 06/11/2024
// Seção de Declarações 
var
   emprestimo, valorfinal, porcentagem : real
   parcelas:real
   inicio
// Seção de Comandos 
   escreva("Qual o valor do empréstimo? ")
   leia(emprestimo)
   escreva("Em quantas parcelas quer pagar? ")
   leia(parcelas)
   porcentagem <- (emprestimo*20)/100
   valorfinal <- (porcentagem + emprestimo) / parcelas
   escreva("O valor de cada parcela é: ", valorfinal:5:2, " R$")
