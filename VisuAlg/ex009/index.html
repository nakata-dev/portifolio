Conversor de temperatura

VisuAlg: converter Fahrenheit para Celsius com uma fórmula simples.

Voltar para VisuAlg Contato

Fahrenheit → Celsius

  • Você lê a temperatura em F (Fahrenheit).
  • Aplica a fórmula: C ← (F − 32) / 1.8.
  • Exibe o resultado formatado: c:4:1 (1 casa decimal).
Fórmula: Celsius = (Fahrenheit − 32) / 1.8 
algoritmo "ConversorFC"
// Função : Conversor de Farenait para Celsius
// Autor : Ailton A. Nakata
// Data : 06/11/2024
// Seção de Declarações 
var
   c, f : real

inicio
// Seção de Comandos 
   escreva ("Qual a temperatura aqui? ")
   leia(f)
   c <- (f - 32) / 1.8
   escreva ("A temperatura em Celsius do Brasil é ", c:4:1)
