VisuAlg: calcular 60% de imposto sobre um valor em dólar.

Voltar para VisuAlg Contato

Imposto sobre importação

  • O programa lê o preço do produto em US$.
  • Calcula o imposto como 60% do valor.
  • Exibe o imposto formatado com duas casas decimais.
algoritmo "ImpostoSP"
// Função :Calcular o Imposto sobre a importação de um produto
// Autor : Ailton A. Nakata
// Data : 06/11/2024
// Seção de Declarações 
var
   preco, imposto : real
inicio
// Seção de Comandos 
   escreva ("Qual o valor do produto em US$ : ")
   leia (preco)
   imposto <- (preco * 60) / 100
   escreva ("O valor do imposto em US$ é ", imposto:5:2)

Voltar
Dica: se você quiser calcular o total final, crie uma variável total e faça total ← preco + imposto para mostrar “produto + imposto”.
