Cálculo de Idade

VisuAlg: calcular idade de forma simples (ano atual − ano de nascimento).

Voltar para VisuAlg Contato

Como funciona

  • O algoritmo pede o ano atual.
  • Depois pede o ano de nascimento.
  • Calcula: idade ← ano_atual − ano_nasc.
  • Exibe o resultado na tela.
algoritmo "Calculo_Idade"
// Função : Calcular a idade da pessoa
// Autor : Ailton A. Nakata
// Data : 06/11/2024
// Seção de Declarações 
var
    ano_atual, ano_nasc, idade: inteiro
inicio
// Seção de Comandos 
    escreva ("Em que ano nós estamos? ")
    leia(ano_atual)
    escreva ("Em que ano eu nasci? ")
    leia(ano_nasc)
    idade <- ano_atual - ano_nasc
    escreva ("Minha idade será ", idade)
