Estruturas de Repetição II (ENQUANTO)

  • C é o contador que começa em 1.
  • Q define quantas vezes a conversão vai acontecer.
  • Enquanto C ≤ Q, o algoritmo pede um valor em reais e converte para dólar.
  • Em cada repetição, C ← C + 1 para avançar o contador.
Observação: a cotação do dólar aqui está fixa em 6.07. Para deixar mais realista, você pode pedir a cotação como entrada (opcional). 
algoritmo "Conversor de Dólar"
// Função : Converter real para dólar
// Autor : Ailton A. Nakata
// Data : 06/11/2024
// Seção de Declarações 
var
   C, Q : INTEIRO
   reais, dolar : real

inicio
// Seção de Comandos 
C <- 1
ESCREVAL("CONTAÇÃO DO DÓLAR HOJE É DE 6.07 R$")
ESCREVAL("QUANTAS VEZES VOCÊ QUER CONVERTER? ")
LEIA(Q)
ENQUANTO C<= Q FACA
   escreva ("Quanto reais eu tenho? R$ ")
   leia (reais)
   dolar <- reais / 6.07
   escrevaL ("Posso comprar US$ ", dolar:5:2)
   C <- C + 1
FIMENQUANTO
