Treino de posicionamento

Veja como background-position muda o “enquadramento” da imagem.

Voltar para HTML Contato

Dica: com background-size: cover, a imagem preenche o bloco e o background-position escolhe qual parte fica visível.

CSS

.bloco{
  background-image: url('imagens/wallpaper003.jpg');
  height: 220px;
  border: 1px solid rgba(0,0,0,0.18);
  border-radius: 16px;

  background-repeat: no-repeat;
  background-size: cover;
}

#q1{ background-position: left top; }
#q2{ background-position: left center; }
#q3{ background-position: right bottom; }
#q4{ background-position: center center; }
#q5{ background-position: bottom left; }
