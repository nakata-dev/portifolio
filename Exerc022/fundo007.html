Demonstração

O container é relative. O conteúdo é absolute e fica no centro com left/top: 50% + translate(-50%, -50%).

CSS essencial

#container{
  position: relative;
}

#conteudo{
  position: absolute;
  left: 50%;
  top: 50%;
  transform: translate(-50%, -50%);
}
